# Viki — Protótipo de Plataforma de Streaming de Doramas

O **Viki** é um projeto acadêmico desenvolvido em 2025, inspirado na plataforma de streaming Rakuten Viki. A proposta foi criar um protótipo de uma plataforma digital voltada à exibição e descoberta de doramas, oferecendo uma interface intuitiva para explorar diferentes títulos.

A aplicação permite navegar por um catálogo de produções, pesquisar conteúdos e acessar vídeos, simulando algumas das funcionalidades presentes em plataformas de streaming.

## Funcionalidades

- Catálogo dinâmico de doramas;
- Exibição de imagens e informações dos títulos;
- Pesquisa de conteúdos;
- Reprodução de vídeos por meio de integração com o YouTube;
- Interface inspirada em plataformas de streaming.

## Tecnologias utilizadas

- **Frontend:** HTML5, CSS3 e JavaScript;
- **Integração de vídeos:** YouTube IFrame;
- **Outras ferramentas:** Inteligência artificial como apoio ao desenvolvimento.

## Minha participação

Participei da construção e personalização da interface do projeto, realizando a seleção de imagens, elaboração de textos e configuração dos links dos vídeos. Também utilizei ferramentas de inteligência artificial como apoio à geração e implementação do código.

## Objetivo do projeto

Desenvolver um protótipo de plataforma de streaming, colocando em prática conhecimentos de desenvolvimento web, estruturação de páginas, estilização com CSS, programação com JavaScript e integração de conteúdos externos.
